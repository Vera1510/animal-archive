# Project

ANIMAL ARCHIVE is an editable Unity 6000.3.16f1 project. Public Web build: https://archive.leungpuisze.com/ .

The loop is animal movement, crop attraction, staff guidance, boarding, contribution, upgrades, automation, a demon encounter, recovery and departure. Keep this loop during maintenance. A separate course submission has different timing parameters and is outside this public repository.

Publish required Unity assets, source, project/package settings, the Web shell and selected audio sources. Exclude caches, deployed binaries, coursework identity, internal historical notes, credentials and machine-specific state.

No game, Unity Editor or persistent preview server is required for Git publication. Existing compile/build results are not equivalent to a new gameplay test.

Background execution is disabled; focus loss suspends simulation, and exit requests cleanup. Normal closed documents/processes no longer execute the game; this does not mean the browser or OS itself consumes zero resources.

Public-source visibility was authorized by the owner. Do not publish course identity fields, private email addresses or credentials. No blanket open-source license is granted; the included font retains its separate license.
